Key security

The private key is the wallet authority.

Bitcoin safety depends on protecting the secret material, not merely protecting the Triplem VIP login.

Client-side handling

Sensitive signing and derivation workflows are performed in the browser.

Watch-only separation

Use an address-only wallet when spending authority is unnecessary.

Export caution

A wallet PDF or private key must be protected because possession can grant control over funds.

Account security is separate

Authenticator, Smart PIN and session controls protect Triplem VIP access, but they do not change the cryptographic authority of a Bitcoin private key.

Finance boundary

Bitcoin wallet activity does not automatically become Accounting ERP entries.

Wallet cryptography and formal bookkeeping solve different problems.

Current behavior

Sending or receiving Bitcoin in the Bitcoin module does not automatically create Accounting journals or operational wallet transactions. If a Bitcoin movement must appear in formal books, record the appropriate accounting effect separately with the organization’s chosen valuation and accounting policy.

Questions

Practical questions about bitcoin wallet tools.

The answers below describe the current Triplem VIP workspace and the boundaries of this operational module.

Where are Bitcoin private-key operations performed?

Triplem VIP is designed so sensitive Bitcoin key workflows remain client-side in the browser rather than being treated like ordinary server-held account data.

Can I use a watch-only wallet?

Yes. A watch-only wallet can load an address for balance and transaction visibility without loading a spendable private key.

Which address styles are supported by a loaded private key wallet?

The current wallet code prepares five address types, including legacy forms, SegWit-compatible forms and Taproot, with the active address selectable for supported wallet actions.

Can Bitcoin transactions be exported?

Yes. The Bitcoin area includes PDF generation for transaction records, and key-bearing wallet export PDFs are deliberately accompanied by security warnings because anyone with the secret can control the funds.
