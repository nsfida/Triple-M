Account security & support

Authenticator 2FA, secure notifications and support that follows the user.

Triplem VIP combines optional standards-based Authenticator App 2FA, recovery codes, opt-in Web Push notifications, guided visitor Live Support and private in-app support messaging. These features are designed to improve account awareness without exposing passwords, Smart PINs or private financial records.

Explore Triplem VIPTechnical security

Authenticator App 2FA

Users can optionally add a TOTP authenticator as a second sign-in factor. Enrollment supports a QR code or manual secret key, followed by verification of a six-digit code. Single-use recovery codes provide an offline fallback if the authenticator app is unavailable.

A remembered session can continue on the same trusted browser according to the user’s Remember Me choice. A fresh browser or device must complete the second factor when 2FA is enabled.

Secure Web Push notifications

Users can explicitly opt in to browser push notifications on supported devices. Push delivery can alert subscribed devices to relevant account, message and support activity even when the Triplem VIP page is closed. The notification channel does not bypass normal sign-in or Smart PIN protections.

On iPhone and iPad, browser Web Push requires the website to be added to the Home Screen and opened as a web app before notification permission can be granted.

Visitor Live Support: guided AI to Agent handoff

Public visitors begin with a guided support experience focused on Triplem VIP product questions. Every answer can offer related next questions and a clear option to request a real Agent. Free typing becomes available after an Agent accepts the conversation, reducing irrelevant automated responses while preserving a natural human support path.

Private support for registered users

Signed-in Triplem VIP users can use the authenticated in-app messaging channel where enabled. The messaging experience and browser notification layer work together so important support activity can be surfaced while the private workspace remains protected by the normal account security flow.

Recovery without credential disclosure

Triplem VIP does not need administrators to view existing passwords or Smart PINs. Authenticator-protected users can prove the second factor for supported recovery operations. Accounts without 2FA use administrator-assisted password recovery, where a verified temporary password replaces the old password and forces the user to create a new permanent password after sign-in.
