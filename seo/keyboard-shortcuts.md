## Desktop keyboard shortcuts for faster finance workflows

Use compact Ctrl+Alt commands for the active Triplem VIP section without colliding with browser Ctrl+N, and open the in-section Shortcuts tag whenever you need the full key map.

## Fast commands that belong only to the section you are using.

Triplem VIP shortcuts are desktop-only, section-scoped and paused while another dialog or input field is active.

### Section scoped

The same key combination can perform a different valid action in another section because only the active module receives it.

### Hidden on mobile

The Shortcuts tag and shortcut overlay are intentionally unavailable on mobile/touch layouts.

### Overlay directory

Click the desktop Shortcuts tag inside a supported section to see the commands available there.

### No Ctrl+N collision

Browser-reserved Ctrl+N is not used. Triplem VIP uses Ctrl+Alt combinations to avoid opening a new browser window.

### Typing protected

Shortcuts pause while text inputs, selects, textareas or active dialogs need keyboard focus.

### Native actions

Shortcut commands trigger the same module workflows and permission checks as their visible buttons.

## Search and note creation stay equally predictable.

### Assets

Ctrl + Alt + F focuses the Assets search while Assets is active.

### Installments

Ctrl + Alt + F focuses Installments search while Installments is active.

### Notes

Ctrl + Alt + N creates a New Note and Ctrl + Alt + F focuses Notes search.

For example, Ctrl+Alt+T means Transfer Money in Expenses but Loan Taken in the Loan Taken/Returned view. This is safe because the shortcut layer checks the active section before dispatching an action.

## Why the shortcut system is deliberately contextual.

### Why is Ctrl+N not used?

Browsers reserve Ctrl+N for opening a new window. Triplem VIP therefore uses Ctrl+Alt combinations for section actions instead of fighting a browser-level command.

### Do shortcuts appear on mobile?

No. The Shortcuts tag and its directory are desktop-only, and the keyboard handler is not intended to provide these commands on mobile/touch layouts.

### Can one combination mean different things?

Yes, only when the active section makes the meaning unambiguous. Ctrl+Alt+T can transfer money in Expenses and create a Loan Taken in the matching loan view because only that active section receives the command.

### What happens while typing?

Shortcut dispatch pauses while text fields, selects, textareas or active dialogs require keyboard focus, preventing commands from interrupting normal data entry.
