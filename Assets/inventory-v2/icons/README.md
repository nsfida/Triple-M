# Inventory 2.0 icon library

Product and category icons bundled with Triplem VIP so they work offline and never load from another site.

- Source: [Tabler Icons](https://tabler.io/icons) 3.31.0, MIT licence (see `LICENSE-tabler-icons.txt`).
- `icon-manifest.json` lists every icon with a stable id `<category>/<name>`; products store only that id.
- Icon ids are never renamed or removed in later releases, so older products keep their icon. New icons may be added.
- Brand logos are deliberately not included.
